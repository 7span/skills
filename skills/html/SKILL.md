# HTML

## Purpose

Keep markup lean while building UIs. This skill is not tied to a framework, so it is named by purpose.

## Rules

1. Use fewer wrapper `<div>`s. Accomplish the styling or UI with as few `<div>`s as possible instead of wrapping a new `<div>` every time while building complex UIs.
